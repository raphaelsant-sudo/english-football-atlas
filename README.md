# English Football Atlas — protótipo inicial

Este é um site estático: não exige VS Code, Node.js ou instalação de pacotes.

## Publicar pelo GitHub Pages
1. Crie um repositório público chamado `english-football-atlas`.
2. No repositório, escolha **Add file → Upload files**.
3. Envie `index.html` (extraia este ZIP primeiro).
4. Faça commit das alterações.
5. Abra **Settings → Pages**.
6. Em **Build and deployment**, escolha **Deploy from a branch**.
7. Selecione `main` e `/ (root)`, depois **Save**.

O mapa utiliza Leaflet e os mapas do OpenStreetMap, carregados pela internet. A página funciona melhor com conexão externa liberada.

Este protótipo contém somente o Sunderland como primeiro clube. Os demais serão adicionados após conferirmos os dados e coordenadas.
